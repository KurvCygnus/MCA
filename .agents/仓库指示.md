# MeloongCore 代码约定

[仓库指南](../AGENTS.md) · [Shared](Shared/架构分析.md) · [Wpf](Wpf/架构分析.md) · [Tests](Tests/架构分析.md)

本文件约束共享库的代码、注释与公共契约。机械格式由根 `.editorconfig` 决定；本文件只记录无法机械检查的约定。

## 风格与复用

- 使用 C# 13、Nullable、Implicit Usings 与 PolySharp；新代码保持目标框架兼容：`Shared` 为 .NET Standard 2.0，`Wpf` 与 `Tests` 为 .NET Framework 4.8。
- `.editorconfig` 是缩进、换行、空格、`var`、表达式体等机械格式的唯一权威。本文不复制配置值；两者冲突时以 `.editorconfig` 为准。
- 单行成员优先表达式体，多行成员使用块体。
- 不为一两行逻辑添加辅助方法。仅有一个引用的方法或变量优先内联；重复出现三次以上再抽取。
- 新增工具前先查 `Shared/Extensions`、`Shared/General` 与 `Shared/Utils`，避免重复实现。扩展方法放在 `MeloongCore.Extensions`，通用类型放在 `MeloongCore`。
- 用卫语句处理前置条件，减少嵌套。一个方法只做一件事。
- 公共成员必须有中文 XML 文档，至少包含 `<summary>`；有参数、返回值或可预期异常时补 `<param>`、`<returns>`、`<exception>`。私有成员在意图不明显时补简短说明。
- 公共签名显式标注可空性。`!` 只用于已经论证成立的不变量，并在同一行用 `//!` 注明理由。
- 类型、属性、方法、事件使用 PascalCase，局部变量与参数使用 camelCase。测试方法名使用 `被测对象_场景`，例如 `FileUtils_ReadAsString_ReturnsContent`；禁止 `Test1` 一类名称。
- 返回 `Task` 的方法以 `Async` 结尾。除事件处理器外禁止 `async void`。
- 使用 `""` 表示空字符串。行尾注释与代码同一行，`//` 前留一个空格。
- 优先使用 `nameof`、模式匹配、`using` 声明与目标类型 `new`；不为风格引入额外分配。
- 只在本轮修改的文件上应用新格式，存量代码保持原样，避免制造大面积无关 diff。

## 注释与文档

- 注释解释为什么，不解释代码在做什么。简单的赋值、调用和显而易见的控制流不加注释。
- 注释必须自包含：写明当前代码的理由与约束，不引用会话、计划、审查编号或临时任务。
- 记号只用于行注释：
  - `//*` 重要上下文，例如必须保持的调用顺序或跨模块约定。
  - `//!` 反直觉行为、陷阱或必须保留的历史包袱；Rust 代码写成 `// !`。
  - `//?` 困惑点、TODO 或待修复项；TODO 必须写明触发条件或完成标准。
- XML 文档使用标准标签（`<summary>`、`<param>`、`<returns>`、`<exception>`、`<see cref="..."/>`），不混入上述记号。
- 禁止提交注释掉的代码。无主 TODO 直接删除或补上触发条件与完成标准。
- 内部引用使用语言原生语法（C# 用 `<see cref="..."/>`），外部链接使用 Markdown `[文字](url)`。

### 变更规则

- 稳定面只增不删。需要弃用时先加 `[Obsolete("...")]` 并保留至少一个发布周期，PCLA 迁移完成后再删除。
- 稳定成员的行为、默认值、异常语义与线程语义都算契约。修改前搜索 PCLA 调用点，并在提交说明写明影响。
- 稳定面之外的公共类型按内部实现对待，可以重构；重构必须在同一批工作中让 PCLA 编译通过。
- 新增成员默认 `internal`，确有必要跨程序集使用时才声明为 `public`。
- 破坏性变更与 PCLA 的 submodule 指针更新、适配代码放在同一批工作中，禁止先合并再补。

## 测试与验证

- 测试框架是 TUnit。不删除或跳过既有测试；新行为必须带对应测试。
- 测试不得访问真实网络或真实外部服务，I/O 边界使用临时目录与假实现。
- 运行方式：

  ```powershell
  dotnet build Tests\MeloongCore.Tests.csproj -c Release --nologo
  Tests\bin\Release\net48\MeloongCore.Tests.exe
  ```

- `dotnet test` 在 .NET 10 SDK 下因 Microsoft.Testing.Platform 不兼容而不可用；禁止借此绕过测试。
- 基线为 125 项中 124 通过。`Tests\Utils\FileUtilsTest.cs:7` 是已记录的既有失败，与当前改动无关。
- 门槛：三个项目 Release 构建零警告，TUnit 不低于基线；修改公共 API 后额外编译 PCLA。

## 编码与文件

- 所有文本文件使用 UTF-8 无 BOM。
- 换行、结尾空白与最终换行交给 `.editorconfig` 和 `.gitattributes` 处理，不在编辑器中手工制造差异。
- PowerShell 读写文本时显式指定 UTF-8，例如 `Get-Content -Encoding utf8` 与 `Set-Content -Encoding utf8`。
