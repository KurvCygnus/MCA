# Wpf 入口与构建

[代码约定](../仓库指示.md) · [Shared](../Shared/架构分析.md)

构建 WPF 工程使用 Visual Studio 2022 的 `MSBuild.exe`。本项目为通用 Windows/WPF 适配层，依赖 Shared；纯 .NET 逻辑留在 Shared，应用专用外观和页面逻辑留在引用方。

路径相对于 `Wpf/`：

| 场景 | 入口 |
| --- | --- |
| WPF 初始化 | `Main.cs` |
| ToolTip 附加行为 | `Controls/ModernTooltipService.cs` |
| 控件与对象扩展 | `Extensions/WpfExtensions.cs` |
| 旧 Newtonsoft JSON 字符串反序列化 | `LegacyJson/LegacyJsonExtensions.cs` |
| 旧 JSON 文件读取 | `LegacyJson/LegacyFileUtils.cs` |
| 文件、文件夹与消息对话框 | `General/Dialogs.cs` |
| Binding 转换器 | `General/ValueConverters.cs` |
| Windows 权限、窗口与系统操作 | `Utils/WindowsUtils.cs` |

System.Windows.Forms 与 WPF 互操作涉及 DPI、窗口句柄和线程模型；调整相关行为时检查调用线程与窗口归属。

`LegacyJsonExtensions.DeserializeJson`/`DeserializeJson<T>` 与 `LegacyFileUtils.ReadAsJson`/`ReadAsJson<T>` 供引用方沿用旧 Newtonsoft 调用形状：`DateParseHandling.None` 下日期保持字符串，由调用方再转换时刻；空白输入返回 null，解析错误抛 Newtonsoft 原生异常。`ReadAsJson` 的 `type` 参数透传 `FileUtils.ReadAsString`，用于读取引用方嵌入资源。Shared `FileUtils.ReadAsJson` 暂时保留内联 Newtonsoft 实现，迁移到 System.Text.Json 时删除，届时 `LegacyJsonExtensions` 补 `ToJsonNode`/`ToJToken` 桥接。
